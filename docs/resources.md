# Resources

External references for the CYD board and this class of project.

- [ESP32-Cheap-Yellow-Display](https://github.com/witnessmenow/ESP32-Cheap-Yellow-Display) —
  the community reference for the board: pinouts, board revisions, and examples.
- [TFT_eSPI](https://github.com/Bodmer/TFT_espi) — the display driver this
  firmware renders through.
- [FlickerFreePrint](https://github.com/KrisKasprzak/FlickerFreePrint) — from
  the pre-LVGL era, when the firmware drew every pixel itself. No longer
  used.
- [CYD 3.5" case](https://www.printables.com/model/739905-cyd-35-case-esp32-3248s035) —
  a printable enclosure. For the 3.5" ESP32-3248S035 board, not the 2.8"
  ESP32-2432S028R this firmware targets, so it needs adapting.
